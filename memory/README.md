# Durable Memory

This directory holds durable context that should survive across sessions but
does not belong in current status, formal decisions, or canonical state.

## Files

- `operator-preferences.yaml` records durable operator preferences.
- `repo-notes.md` records repo-specific notes that are useful but not formal
  design authority.
- `session-summaries.md` records concise cross-session summaries.

## Discipline

Keep memory compact. Promote decisions, blockers, and current work to their
canonical homes when they become authoritative.
