# Gardening And Entropy Management

This directory records local gardening rules and durable cleanup-pressure
snapshots for an installed harness target.

Use `gardening/rules.yaml` for structured cleanup rules. Use
`gardening/snapshots.md` for copied plan output or notes that should remain
local to this repo.

Run:

```bash
harness garden list
harness garden check
harness garden report
harness garden plan
```
