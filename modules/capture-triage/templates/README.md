# Capture And Triage

This directory is the harness capture inbox and triage register.

Use it for material that is useful but not yet authoritative:

- observations
- possible tasks
- bugs
- questions
- follow-up ideas
- notes that may need promotion later

Promote selected material into the appropriate process domain. Active work
belongs in plans. Rationale belongs in decisions. Unresolved uncertainty
belongs in open questions. Authoritative state belongs in canonical state.
Stable cross-session context belongs in durable memory.
