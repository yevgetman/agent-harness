# Durable Memory

Use this directory for context that should survive across agent sessions but
does not belong in current status, formal decisions, or canonical state.

## Files

- `operator-preferences.yaml` records durable operator preferences.
- `repo-notes.md` records repo-specific notes that are useful but not
  authoritative enough for formal design docs.
- `session-summaries.md` records concise cross-session summaries.

## Discipline

Keep memory durable and compact. Promote decisions, blockers, and current work
to their canonical homes when they become authoritative.
